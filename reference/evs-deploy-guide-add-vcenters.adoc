= NetApp Disaster Recoveryにオンプレミスおよび Amazon EVS vCenter クラスターを追加する
:allow-uri-read: 


[role="lead"]
サイトを作成したら、各サイトの vCenter クラスタを NetApp Disaster Recovery に追加します。サイトのタイプによって、そのサイトの vCenters に対して NetApp Disaster Recovery が必要とするアクセス権限が決まります。Amazon EVS vCenters とオンプレミスの vCenters は、同じ接続情報および認証情報を使用します。

.各サイトにvCenterを追加する手順
. *サイト* オプションから、必要なサイトの *vCenter の追加* を選択します。
+
image:evs-add-vcenter-1.png["vCenterオプションの追加"]

. [vCenter サーバーの追加] ダイアログ ボックスで、次の情報を選択または入力します。
+
.. AWS VPC 内でホストされるNetApp Consoleエージェント。
.. 追加する vCenter の IP アドレスまたは FQDN。
.. 必要に応じて、ポートをvCenterサーバが使用する TCP ポートに変更してください。
.. 以前に作成したアカウントの vCenter ユーザー名。NetApp NetApp Disaster Recoveryが vCenter を管理するために使用します。




. 組織が外部認証局 （CA） または vCenter エンドポイント証明書ストアを使用している場合は、「自己署名証明書を使用する」のチェックを外します。それ以外の場合は、チェックボックスにチェックを入れたままにしてください。
+
.. *追加*を選択します。
+
image:evs-add-vcenter-2-3.png["vCenter の追加ダイアログボックス"]
