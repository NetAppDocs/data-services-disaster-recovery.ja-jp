= NetApp Disaster Recoveryですべてが正常に動作していることを確認する
:allow-uri-read: 


[role="lead"]
NetApp Disaster Recovery でレプリケーションプランを追加したら、続行する前にプランが *Healthy* 状態であることを確認してください。

図: レプリケーション プラン ページimage:evs-replication-plan-post-create.png["レプリケーションプランページ"]

NetApp Disaster Recovery は、ONTAP クラスタ、vCenter クラスタ、および仮想マシンを含むすべてのコンポーネントがアクセス可能で保護の準備が整っているかどうかを確認するための一連のテストを実行します。これはコンプライアンスチェックと呼ばれ、定期的に実施されます。

レプリケーション計画ページには、以下の情報が表示されます：

* 最後のコンプライアンスチェックのステータス
* レプリケーションプランのレプリケーション状態
* 保護された（ソース）サイトの名前
* レプリケーションプランによって保護されているリソースグループのリスト
* フェイルオーバー（宛先）サイトの名前
