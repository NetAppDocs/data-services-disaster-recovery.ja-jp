= NetApp Disaster Recoveryの概要
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
NetApp Disaster Recovery を使用すると、次の目標を達成できます。

* link:../use/dashboard-view.html["災害復旧計画の健全性を確認する"]
* link:../use/sites-add.html["サイトにリソースを追加する"]
* link:../use/resource-group.html["データソースを整理するためのリソースグループを作成する"]
* link:../use/drplan-create.html["災害復旧計画を作成する"]
* link:../use/replicate.html["VMwareアプリを複製する"]プライマリサイトからクラウド上の災害復旧リモートサイトへSnapMirrorレプリケーションを使用
* link:../use/migrate.html["アプリケーションの移行"]プライマリサイトから別のサイトへ
* link:../use/failover.html["フェイルオーバーをテストする"]リソースを中断することなく
* 災害時には、link:../use/failover.html["プライマリサイトをフェイルオーバーする"]
* 災害が解決した後、災害復旧サイトからプライマリサイトへlink:../use/failback.html["フェイルバック"]
* ジョブモニタリングページでlink:../use/monitor-jobs.html["災害復旧オペレーションの監視"]
